# 砚 · INKBOARD

单文件、零依赖的**实时协作白板原型**。一个 `inkboard.html` 丢进浏览器就能跑，没有构建步骤，没有 npm，没有 CDN 请求。

深色顶栏 + 暖白画布 + 浅灰双层网格，交互与视觉对齐 Miro 一类的在线白板。

## 直接打开

```bash
open inkboard.html          # macOS
# 或者随便一个静态服务器
python3 -m http.server 8000
```

## 功能

| 能力 | 说明 |
| --- | --- |
| 无限画布 | 拖拽平移（空格 / 中键 / 平移工具），滚轮以光标为锚点缩放，0.15×–5× |
| 便签 | 点击添加、拖拽移动、双击编辑、右键删除、六色切换、四角 resize |
| 画笔 | 自由绘制，1–26px 粗细，四种墨色 |
| 连线 | 从一张便签拖到另一张，箭头自动贴合边界，便签移动/删除时跟随 |
| 选择 | 点选、Shift 加减选、拖拽框选、多选整体移动、四角手柄缩放 |
| 顶部工具栏 | 工具 / 颜色 / 笔宽 / 撤销重做 / 协作者状态 / 缩放 |
| 迷你地图 | 右下角总览，可点击或拖拽定位视口，一键适应画布 |
| 其他 | 撤销重做、右键菜单、空状态引导、模拟协作者光标（可关） |

### 快捷键

| 键 | 作用 |
| --- | --- |
| `V` / `N` / `P` / `L` / `H` | 选择 / 便签 / 画笔 / 连线 / 平移 |
| 空格、鼠标中键 | 临时平移 |
| 双击空白 | 新建便签 |
| `⌘Z` / `⇧⌘Z` | 撤销 / 重做 |
| `⌘D` / `⌘A` | 复制选中 / 全选 |
| `⌘0` / `⌘±` / `⇧1` | 100% / 缩放 / 适应画布 |
| `Delete` | 删除选中 |

## 实现要点

渲染分三层，这是整个原型最关键的结构决策：

- **`#scene` canvas** — 网格与笔迹在世界坐标下绘制（笔迹随缩放变粗）；连线、框选、协作者光标在**屏幕坐标**下绘制，保证线宽与箭头尺寸恒定。
- **`#world` div** — 整体 `transform: translate(x,y) scale(k)`，承载便签 DOM。`contenteditable` 承担双击编辑；选中环用 `calc(1.8px / var(--z))` 反向补偿缩放，永远 1.8px。
- **`#overlay` div** — 屏幕坐标层，放选中框、四角 resize 手柄、浮动操作条，尺寸不随缩放变化。

其他：

- 撤销/重做用 JSON 快照（便签 + 笔迹 + 连线），实现简单、状态完全一致，代价是内存占用，原型规模下完全够用。
- 连线只存两端便签 id，每帧按矩形边界求交点重算端点，所以平移缩放不会错位。
- 迷你地图按「内容包围盒 ∪ 当前视口」自适应求缩放，内容为空时退化为只显示视口。
- 网格在缩放过小时自动抽稀（步长 ×4），避免网格线糊成一片灰。
- 全站 `prefers-reduced-motion` 降级。

## 已知边界

- **协作是模拟的**。3 个协作者头像和 2 个游动光标都是前端假数据，没有 WebSocket，没有 CRDT。要真做多人同步，需要在服务端加房间 + 操作广播，冲突合并建议 Yjs / Automerge。
- 笔迹不可单独选中或擦除，只能整体撤销。
- 未做持久化，刷新即清空。

## 设计定调

石墨黑顶栏 `#14161B`（叠 4% SVG 噪点避开塑料感）+ 暖白画布 `#FAFAF9`，强调色取**朱砂 `#E04A1F`** —— 刻意避开白底蓝紫渐变那套默认配色。便签用纸感六色，阴影带环境色而非纯黑。
